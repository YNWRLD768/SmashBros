1. What is Our Module:
      - Algorithms are a specific set of instructions for a computer to execute a specific task; data structures are specialised layouts for organizing, storing and managing data in a computers memory so it can be accessed and modified more efficiently; Connectionist AI is an approach in which a system can learn useful patterns by doing operations with numerical units (artificial neurons) that are connected together.
      - Our module as a whole, starts with the fundamental building blocks of computing, algorithms that run through data structures, up until how we use those fundamental knowledge to build something meaningful and more complex in Connectionist AI.    

2. Expect to be challenged by the topics, as many may seem unheard of, abstract, or new. Expect to get questions wrong and struggle to piece together the concepts. However, do expect to be guided well by the use of many worked examples, diagrams, and a variety of study materials (PPT, Study Guide, Video Tutorials) to suit everyone's learning style.
